System Architecture

Frontend — client/src/
V
Views (6 pages)
Dashboard, Inventory, Orders, Demand, Spending, Reports
C
Components
FilterBar, modals (Inventory, Backlog, Cost, Product, Profile, Tasks), ProfileMenu, LanguageSwitcher
~
Composables
useFilters (singleton filter state), useAuth (user + tasks), useI18n (t() translations)
A
api.js
Axios wrapper — all 15+ API calls, builds query params from filter state
↕ REST / JSON ↕
Backend — server/
F
main.py
20+ FastAPI endpoints, Pydantic response models, CORS middleware
f
apply_filters()
Shared utility — warehouse, category, status. Skips if value is "all" or None
t
filter_by_month()
Direct month match (2025-01) or quarter (Q1-2025) via QUARTER_MAP
D
mock_data.py
Loads all 7 JSON files into module-level variables at startup. No persistence.
{ }
data/*.json
inventory, orders, demand_forecasts, backlog_items, spending, transactions, purchase_orders

Filter Data Flow

User Interaction
FilterBar.vue
4 dropdowns: Time Period, Warehouse, Category, Order Status
→
Composable
useFilters()
Singleton — shared reactive refs across all views
→
API Client
api.js
Builds URLSearchParams, calls axios with query string
→
FastAPI Endpoint
main.py
Receives optional query params, calls apply_filters()
→
Response
Pydantic JSON
Validated, typed — stored in Vue refs as raw data

API Endpoints

Endpoint Purpose Supported Filters
GET /api/dashboard/summary KPI aggregates (inventory value, low stock, pending orders, revenue) warehouse category status month
GET /api/inventory Full inventory item list warehouse category
GET /api/orders Order list with status warehouse category status month
GET /api/demand Demand forecasts none
GET /api/backlog Backlog items with PO status flags none
GET /api/spending/summary Spending totals none
GET /api/spending/monthly Month-by-month spend breakdown none
GET /api/spending/categories Spend by category none
GET /api/spending/transactions Recent transactions none
GET /api/reports/quarterly Quarterly stats none
GET /api/reports/monthly-trends Monthly trend data none

Testing

Backend — pytest

FastAPI TestClient via httpx. Fixtures in tests/backend/conftest.py.

# All tests
cd tests && uv run pytest backend/ -v

# Single file
uv run pytest backend/test_inventory.py -v

# Single function
uv run pytest backend/test_inventory.py::test_get_inventory -v

Frontend — Playwright

Browser testing via MCP Playwright tools. No unit test framework configured.
